# PLAN_v39 — ШАГ 095: офлайн-режим и явные сетевые флаги

Freesound теперь использует локальный кэш по умолчанию, даже если в окружении уже есть ключ и доступен HTTP-клиент. Удалённый поиск или загрузка доступны только при `allow_online=True` либо при явной пользовательской настройке `{"network": {"online": true}}` в `data/settings.json`. Некорректная, отсутствующая или строковая настройка не считается согласием на сетевой запрос.

Проверки обновлений также безопасны по умолчанию. `updater --git-status` и `updater --check URL` возвращают честный offline-status и не выполняют `git ls-remote` или HTTP, пока пользователь не передаст `--online` или не включит ту же настройку. Локальные install/rollback/backup действия updater не затронуты.

Приёмка: изолированные моки доказали отсутствие вызовов внешнего HTTP/Git по умолчанию и контролируемую работу при явном opt-in; `python3 main.py --ai --dry-run` завершился без сетевой зависимости, с честными fallback для отсутствующих model deps/weights. Его runtime backup был удалён после проверки, чтобы восстановить чистый data inventory. Полный `pytest tests/ -q` — **226 passed**; `compileall` успешно; AST audit — **0 dead imports**; data inventory — **73 managed, 0 unknown, 0 invalid**.

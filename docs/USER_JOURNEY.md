# Пользовательский путь: текущие действия и целевая приёмка

Карта действий основного мастера: `desktop/src/core/journey.js`. Она читается
непосредственно окном, не является ещё одной копией бизнес-логики генерации.

| Этап | Действие в текущем окне | Наблюдаемый результат | Что ещё не принято |
|---|---|---|---|
| Замысел | ввести тему/ориентир, Далее | настройки сохранены или показана ошибка | полный рецепт, длительность, язык, голос |
| Подготовка | согласие сети, Проверить; открыть Модели и загрузки | сообщения, файлы, причина отказа, повтор/стоп | все backend и inference |
| Создание | Создать трек | процесс и отчёт с типом/ошибкой | законченная песня и передача полного плана |
| Результат | прослушать, посмотреть путь/ограничения | плеер либо ошибка чтения | отдельная правка куплета, история и полноценный экспорт проекта |

## Что изменено сейчас

На каждом этапе видна карточка «Что делать сейчас»: действие, ожидаемый выход,
ограничение и кнопка в нужный существующий раздел. Во время работы переход в
другой раздел не считается отменой задачи. При недоступной карте/навигации —
явная ошибка, не пустое пространство. Кнопка повторного создания не названа
редактированием готового куплета. Не добавлены поля, которые backend игнорирует.

## Целевая приёмка T0049–T0050

Новый пользователь без терминала проходит установку, выбор цели и параметров,
подготовку совместимого backend, генерацию, плеер, сохранение, повторную правку
и восстановление. Нужны реальные наблюдения прохождения и артефакты результата.
DOM-тест карточек и запуск Electron этого не доказывают. Эти пункты **blocked**:
сама генерация/полный рецепт/проектная правка пока не приняты. Не закрывать их
словами «пользовательский путь нарисован».

Контракт рецепта `app/core/recipe.py` пока не переподключён к agent UI целиком;
разрыв передачи параметров остаётся в очереди (пакет 11). Эта карта лишь делает
его явным и не создаёт ещё один несовместимый recipe API.

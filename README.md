Локальная музыкальная студия в разработке. Источник версии — [`version.json`](version.json).

Установщик содержит код Python-пайплайна. Релизная сборка включает встроенный Python; тяжёлые движки и веса готовятся отдельно с разрешением сети.

Загрузки требуют явного согласия. Для всех backend офлайн-готовность ещё не подтверждена.

MIT относится к коду приложения, не ко всем весам, сэмплам или голосам. Коммерческие права ресурсов требуют отдельной проверки; реестр пока неполон.

- **Инструментал — не принят.** Музыка без вокала; реальный WAV, плеер и экспорт. Сквозная нейрогенерация из установленного приложения не принята.
- **Песня со своей записью — не принят.** Инструментал и собственная спетая запись в согласованном миксе. Передача рецепта и голоса в основной рендер требует исправления и проверки.

## Установка Windows

1. Откройте [последний опубликованный релиз](https://github.com/ttklon/ZS-MUSIC-MAKER/releases/latest).
2. Выберите `ZS-Music-Maker-Setup-<версия>.exe`, закройте старое окно и установите приложение.
3. Откройте «Создание трека». «Модели и загрузки» показывает подготовку; «Настройки» — сетевое согласие и пути.
4. При ошибке сохраните отчёт кнопкой «Сохранить ошибки». Не удаляйте проекты и веса ради повторной установки.

Статус подписи зависит от сборки; неподписанный EXE может вызвать предупреждение SmartScreen.
Успешная установка не означает, что все модели подготовлены и генерация песни принята.
Не вводите пароли или токены в приложение для обычной локальной генерации.
